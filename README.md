# Student Registration Form

## Project Overview

The Student Registration Form is a beginner-friendly web development project created using HTML, CSS, and JavaScript. The main purpose of this project is to provide a simple and user-friendly interface for collecting and managing student information.

Users can enter student details such as name, age, and course through the registration form. After submitting the details, the student information is displayed in a list on the webpage. This project also includes basic form handling and dynamic content updates using JavaScript.

## Features

- Simple and user-friendly registration form.

## Technologies Used

- **HTML** – To create the structure of the registration form.
- **CSS** – To style the webpage and improve its appearance.
